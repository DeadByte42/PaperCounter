# Paper Counter

## Описание
Программа выполняет подсчет листов различного размера в PDF документах и перводит их в эквивалент А4

## Функции
- Различные режимы представления статистики по документам
- Различные опции учета размеров листов
- Рекурсивный поиск документов в папках
- Поддержка чтения документов из архивов
- Поддержка чтения документов из файлов e-mail
- Очередь загрузки с индикацией прогресса
- Интеграция в контекстные меню Проводника
- Поддержка перетаскивания (упорядочивание, добавление и объединение документов)

## Технические особенности
- Файл COM.Server.exe необходим для интеграции в контекстные меню
- Файлы pdfium_64.dll и pdfium_86.dll необходимы для открытия PDF
